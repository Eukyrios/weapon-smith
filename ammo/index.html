Early days. This site is being written as the game is read. The RM277 is done — every slot listed and every attachment read — and it is the only one of 66 so far. A tick on a weapon in the list means the same has been done for it. AR-57, MCX LT have lists and are still being read. I enter this by hand, one attachment at a time, so the first few guns will take a while. It gets faster as it goes: most of what a new gun takes is already catalogued, so there are fewer attachments left to add each time. Every other weapon page carries what the catalogue knows and says so. See the AR-57 → See the MCX LT → See the RM277 →
