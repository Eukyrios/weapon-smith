Early days. This site is being written as the game is read, and one of 66 weapons has an attachment list so far — the RM277. I enter this by hand, one attachment at a time, so the first few guns will take a while. It gets faster as it goes: most of what a new gun takes is already catalogued, so there are fewer attachments left to add each time. Every other weapon page carries what the catalogue knows and says so.
